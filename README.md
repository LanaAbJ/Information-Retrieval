# Information Retrieval System

This project implements a simple yet effective Information Retrieval (IR) system designed to improve document search based on user queries.

The system indexes a diverse corpus of documents focused on topics such as Space and Cuisines. When a user submits a query, the system processes and ranks documents based on their relevance.

TF-IDF (Term Frequency–Inverse Document Frequency) is used to represent documents numerically, while cosine similarity is applied to measure the similarity between the query and indexed documents. This ensures that the most relevant documents are retrieved and displayed first.

# Key Features
- Document indexing and preprocessing
- TF-IDF vectorization
- Cosine similarity-based ranking
- Query-based relevance scoring
- Efficient retrieval of top-matching documents

# Technologies Used
- Python
- TF-IDF (scikit-learn / custom implementation)
- Cosine Similarity
- Text preprocessing techniques

# Outcome
The system successfully retrieves the most relevant documents based on user input, demonstrating the core principles of search engines and ranking algorithms.
